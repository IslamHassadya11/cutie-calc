## ✨ Features

🎀 **Beautiful pastel design** — soft gradients, rounded buttons with 3D shadows, ripple effects on every tap

🌊 **Animated bubble background** — floaty little bubbles that change color with the theme

💫 **Spinning decorations** — flowers and stars that spin around the card

⌨️ **Keyboard support** — type numbers and operators directly, no clicking needed

🔬 **Scientific mode** — click *Scientific* to reveal a full panel of extra functions:

| Function | What it does |
|----------|-------------|
| `sin` `cos` `tan` | Trigonometry |
| `INV` | Flip to inverse trig — `asin`, `acos`, `atan` |
| `√x` | Square root |
| `∛x` | Cube root |
| `x²` `x³` | Quick powers |
| `xʸ` | Any power — enter base, press xʸ, enter exponent, press = |
| `log` | Base-10 logarithm |
| `ln` | Natural logarithm |
| `n!` | Factorial |
| `π` | Pi (3.14159…) |
| `e` | Euler's number (2.71828…) |
| `\|x\|` | Absolute value |
| `1/x` | Reciprocal |

🌡️ **DEG / RAD toggle** — switch angle units for trig functions
