Project: cutie-calc
✨ What's inside:
Pastel gradient background with floating animated bubbles
Lucide icons (open source MIT license) for the sparkles, equals, delete & refresh buttons
Spinning flower/star decorations around the card
Ripple effect on every button press
Keyboard support — you can type numbers and operators!
Full calculator logic: + − × ÷, percent %, sign toggle +/−, backspace, clear
❤️ Dev Mode
Click the ❤️ Dev Mode button in the top-right corner — the whole calculator flips to a dark red/purple night
theme with  glowing neon buttons and the footer changes to 
running on ❤️ and caffeine. Click again to go back to pastel mode.

🔬 Scientific Panel
Click Scientific ▾ to expand 16 extra functions:
Trig: sin, cos, tan — with a DEG/RAD toggle
INV button — press it first, then sin/cos/tan to get asin/acos/atan (it glows pink when active!)
Roots: √x (square root), ∛x (cube root)
Powers: x², x³, and xʸ (enter base → press xʸ → enter exponent → press =)
log, ln, n! (factorial), |x| (absolute value), 1/x (reciprocal)
Constants: π and e
